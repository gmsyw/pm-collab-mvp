## 2. 安全提示（发布/部署必读）

1. **首次启动请立即改密**：控制台打印的随机密码仅出现一次，登录后通过右上角「修改密码」更换；改密后其他已登录会话立即失效。
2. **不要提交 `.env` 与 `data/`**：二者已在 `.gitignore` 排除。`PM_SECRET_KEY`、`PM_BOOTSTRAP_PASSWORD` 等敏感值只应存在于本地 `.env`，切勿推送到公开仓库。
3. **生产环境显式配置强密钥**：部署时通过 `PM_SECRET_KEY` 设置高熵密钥；未设置则每次「首启」会重新随机生成（仅对全新库生效，老库不受影响）。
4. **运维脚本走环境变量**：`smoke.py` / `acceptance_flow.py` / `close_tasks.py` 登录读取 `PM_COLLAB_PASSWORD`（可选 `PM_COLLAB_USER`，默认 `admin`），源码不再含明文口令。
5. **数据不入库**：五库正文存于 `data/`，仓库仅含索引元数据，发布不会泄露真实项目资料——但仍请自行确认 `data/` 未被强制加入版本库。

## 3. 兼容性与升级说明

- **既有库升级平滑**：`db_bootstrap` 在启动时自动补齐缺失列；`token_valid_from` 为 `NULL` 的老账号不受旧令牌吊销影响（改密后再生效）。
- **端口与访问**：默认监听 `127.0.0.1:8000`（由 `uvicorn --port` 或 `PM_PORT` 横幅覆盖）；Web UI 在 `/`，交互式 API 文档在 `/swagger`（前端「文档库」已占用 `/docs`）。
- **依赖无新增专有项**：前后端依赖沿用既有宽松许可组件，无破坏性变更。

## 4. 测试结论（详见 `docs/testing/` 报告）

- **单元/集成 pytest**：全量 **84 项通过（exit 0）**，含既有回归与对抗用例（`test_l1_adversarial.py` 并发竞态、非法迁移、越权签字、伪造令牌等）。
- **端到端冒烟 `scripts/smoke.py`**：派单→回执→完成→回收→台账 主链路通过（需先设置 `PM_COLLAB_PASSWORD`）。
- **改密与令牌吊销运行时实测**：旧令牌改密后即 401、新口令可登录、错误旧口令 400、弱口令 422，全部符合预期。
- **测试中发现并修复 1 项安全缺陷（DEF-04）**：初版吊销判断在 SQLite 下因「naive datetime 时区错位约 8h」与「JWT iat 整数秒 vs token_valid_from 亚秒精度」导致旧 token 不吊销或新 token 被误吊销；已修复为「UTC 归一 + 整数秒比较」并回归通过。详见 `docs/testing/PM-Collab 开源版全面测试报告-V1.2.0.md`。
- **发布物自检**：仓库根/LICENSE、.gitignore、README、CHANGELOG、CI 齐备；工作区无默认口令/密钥字面量残留。
